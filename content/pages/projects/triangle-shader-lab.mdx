<Section id="overview" eyebrow="Problem" title="User need">
  <p>
    I wanted to learn WebGPU from the ground up — not by reading specs in isolation, but by writing real WGSL shaders and seeing them render immediately. The lab needed to be source-first: every demo should correlate directly to the code that produced it, with a minimal UI that keeps the focus on the canvas.
  </p>
</Section>

<Section id="approach" eyebrow="Solution" title="What I built">
  <p>
    A WebGPU learning lab built with Next.js, TypeScript, WGSL, and Bun. It ships two canonical demos — a hello triangle and a textured cube — each with source-first exploration so you can trace code to render output. The UI is intentionally minimal, focused on the canvas. The project was originally forked from leaf-js but has been completely rewritten with no shared code. It static-exports to <code>docs/</code> for GitHub Pages via <code>bun run build:pages</code>.
  </p>

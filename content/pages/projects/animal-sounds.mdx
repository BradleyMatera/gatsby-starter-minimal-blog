<Section id="overview" eyebrow="Problem" title="User need">
  <p>
    I wanted a simple, offline-capable soundboard app to learn static export with Next.js 14 and Bun. The app needed to ship its own audio files so it works without a network, keep favorites and usage stats without a backend, and deploy cleanly to GitHub Pages with proper base path handling.
  </p>
</Section>

<Section id="approach" eyebrow="Solution" title="What I built">
  <p>
    A static Next.js 14 soundboard deployed to GitHub Pages. Audio ships from <code>public/audio</code> as offline-ready MP3s, and imagery comes from bundled assets with optional Pexels enrichment. Analytics and favorites persist locally in <code>localStorage</code> — no server required. A GitHub Actions workflow handles the static export with <code>NEXT_PUBLIC_BASE_PATH</code> injection so asset paths resolve correctly under the GitHub Pages subdirectory.
  </p>
  <div className="grid-two">
    <Card>
      <h3 className="feature-card__title">User interface</h3>
      <ul className="feature-list">
        <li>Navbar with navigation and theme toggle</li>
        <li>Hero section introducing the soundboard</li>
        <li>Filters for browsing sounds by category</li>
        <li>Favorites bar for quick access to saved sounds</li>
        <li>Sound cards with playback controls</li>
        <li>Stats overview showing usage analytics</li>
        <li>NextUI components with Tailwind CSS styling</li>
      </ul>
    </Card>
    <Card>
      <h3 className="feature-card__title">Technical implementation</h3>
      <ul className="feature-list">
        <li>Next.js 14 static export for GitHub Pages</li>
        <li><code>lib/base-path.js</code> for base path resolution in static hosting</li>
        <li><code>lib/analytics.js</code> for local analytics load/save/summarize</li>
        <li>localStorage persistence for favorites and usage stats</li>
        <li>GitHub Actions workflow with <code>NEXT_PUBLIC_BASE_PATH</code> injection</li>
        <li>Optional Pexels API for image enrichment (disabled during static export)</li>
        <li>Offline-ready MP3s shipped from <code>public/audio</code></li>
      </ul>
    </Card>

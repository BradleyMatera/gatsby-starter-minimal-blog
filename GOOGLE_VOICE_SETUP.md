# Google Voice Setup for Business — Bradley Matera Web Development

## Goal
Set up a Google Voice number that acts as a business answering machine:
- Records incoming calls
- Emails you the recording
- Emails you a transcript
- Lets you listen to messages online
- Option to read transcripts

## Step-by-Step Setup

### 1. Create a dedicated Google account (if needed)
If you don't want to use your personal Google account, create one like:
- bradleymatera.dev@gmail.com
- matera.web.dev@gmail.com

### 2. Get a Google Voice number
1. Go to https://voice.google.com
2. Sign in with your business Google account
3. Click "Get a Google Voice number"
4. Choose a number with an 815 area code (Northwest Illinois) if available
   - If 815 is not available, try 779 (Rockford area overlay code)
   - If neither is available, any US number works — it's VoIP, not tied to location
5. Verify with your existing phone number (your cell)

### 3. Configure voicemail settings
1. In Google Voice, go to Settings (gear icon)
2. Under "Voicemail", enable:
   - **Voicemail transcription** — automatically transcribes messages
   - **Email voicemail notifications** — enter bradmatera@gmail.com
   - **Forward voicemail recordings to email** — sends the audio file
3. Under "Do Not Disturb", you can set hours when calls go straight to voicemail

### 4. Set up call screening (optional but recommended)
1. Settings > "Calls" > enable "Call screening"
2. Callers will be asked to say their name before connecting
3. You can choose to answer or send to voicemail

### 5. Set up a professional voicemail greeting
Record something like:
> "You've reached Bradley Matera, web developer serving Durand, Davis, Rockford, and Northwest Illinois. I'm not available right now, but please leave your name, phone number, and a brief message about your project. I respond within 24 hours. If you prefer email, reach me at bradmatera@gmail.com. Thanks for calling."

### 6. Get the phone number for the website
Once set up, you'll have a number like (815) 555-1234.
Add this number to:
- The website header (I'll add this once you have the number)
- Google Business Profile (update your existing profile)
- The LocalBusiness schema on the website
- All city landing pages
- The pricing page
- The contact page

### 7. Embed on the website (optional)
Google Voice doesn't have an official embed widget, but you can:
- Add the number as a clickable `tel:` link in the header
- Add a "Call me" button that links to `tel:+18155551234`
- The voicemail-to-email feature handles the "answering machine" part automatically

## Cost
- Google Voice: **Free** for personal use
- Google Workspace (if you want a business number): $6/user/month
- For a sole proprietor, the free personal version is sufficient

## NAP Consistency (Important for Local SEO)
Once you have the number, make sure it appears EXACTLY the same everywhere:
- Website header: (815) 555-1234
- Google Business Profile: (815) 555-1234
- Footer of every page: (815) 555-1234
- Schema markup: +18155551234

Google uses NAP (Name, Address, Phone) consistency as a local SEO ranking factor.
Inconsistent phone numbers across the web can hurt your local search rankings.
